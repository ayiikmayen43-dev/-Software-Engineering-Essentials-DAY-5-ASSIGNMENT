# A. User Manual Procedure: Create a GitHub Repository and Make a First Commit

## Purpose

This procedure explains how to create a new repository on GitHub and add the first file (a README) using the GitHub website. It is intended for a first-semester computing student with basic computer literacy and no previous experience creating a repository.

## Prerequisites

Before starting, make sure you have:

- A computer with a working internet connection.
- A web browser such as Chrome, Firefox, or Edge.
- A GitHub account that you can sign in to.
- Access to the email address or other sign-in method connected to your GitHub account.
- A short project name and a one-sentence description.

> This procedure uses the GitHub website, so Git does not need to be installed on the computer.

## Procedure

1. **Open the GitHub website.**  
   Expected result: The GitHub home page appears in your browser.

2. **Sign in to your GitHub account.**  
   Expected result: Your GitHub dashboard is displayed.

3. **Open the create menu by selecting the plus (+) icon in the top-right corner.**  
   Expected result: A menu containing the option to create a new repository appears.

4. **Select “New repository” from the menu.**  
   Expected result: The repository creation form is displayed.

5. **Enter a unique name in the “Repository name” field.**  
   Expected result: The repository name appears in the field and GitHub accepts it if it is available.

6. **Enter a short explanation in the “Description” field.**  
   Expected result: The description appears below the repository name.

7. **Choose the repository visibility setting (Public or Private).**  
   Expected result: The selected visibility option is marked.

8. **Select the option to add a README file.**  
   Expected result: The README option is enabled, so GitHub will create the first file with the repository.

9. **Select “Create repository.”**  
   Expected result: GitHub opens the new repository page and displays the README file.

10. **Open the README file using the edit (pencil) icon.**  
    Expected result: The README editor opens with the current file content.

11. **Add a short introduction to the README editor.**  
    Expected result: The editor displays the project introduction you entered.

12. **Select “Commit changes.”**  
    Expected result: GitHub saves the README update as a commit and shows the updated file in the repository.

## Screenshot to Include

**Screenshot description:** Capture the repository page after the first commit. The screenshot should show the repository name near the top, the README file in the file list, the README introduction, and the latest commit message. Hide any private information before sharing the screenshot.

## Troubleshooting

**Problem: The README changes do not appear on the repository page.**

**Likely cause:** The changes were typed into the editor, but the “Commit changes” button was not selected.

**Solution:** Open the README editor again, confirm that the text is present, and select “Commit changes.” Return to the repository page and refresh it. The updated README should now be visible.

## Completion Check

The procedure is complete when the repository page opens successfully and the README file contains the introduction saved in the first commit.
